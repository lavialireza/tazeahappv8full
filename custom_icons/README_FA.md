# لوگوهای سفارشی تعزیه استودیو

برای تغییر آیکن روی صفحه اصلی گوشی، تصویر PNG مربعی خود را با یکی از نام‌های زیر در همین پوشه قرار دهید و APK را دوباره بسازید:

- `admin.png` — نسخه رسمی مدیر (Admin)
- `viewer.png` — نسخه رسمی کاربر (Viewer)
- `admin_test.png` — نسخه آزمایشی مدیر (QA Admin)
- `viewer_test.png` — نسخه آزمایشی کاربر (QA Viewer)

## نکات
- اندازه پیشنهادی: 512×512 پیکسل؛ PNG با پس‌زمینه شفاف یا رنگی قابل قبول است.
- نام فایل باید دقیقاً مطابق فهرست بالا باشد؛ پسوند `.png` کوچک باشد.
- اگر فایلی وجود نداشته باشد، برای همان نسخه آیکن پیش‌فرض پروژه استفاده می‌شود.
- هر چهار فایل مستقل‌اند؛ تغییر لوگوی QA لوگوی نسخه رسمی را تغییر نمی‌دهد.
- اسکریپت ساخت، اندازه‌های موردنیاز اندروید و آیکن adaptive را خودکار تولید می‌کند. به نصب Pillow یا ابزار تصویرسازی جداگانه نیاز نیست؛ Java موردنیاز ساخت اندروید کافی است.
- تغییر آیکن نیازمند ساخت APK جدید و نصب/بروزرسانی آن روی گوشی است.
- این قابلیت شناسه برنامه‌ها، امضای APK، کلید انتشار، سرور بروزرسانی و آدرس مرورگر محلی را تغییر نمی‌دهد.
